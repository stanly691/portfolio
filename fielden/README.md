# FIELDEN

React / TypeScript / Vite lifestyle storefront concept.

Run: npm install; npm run dev. Build: npm run build.

Original FIELDEN vector identity, Barlow Condensed display typography and Space Grotesk UI typography. 24 AI-generated compositions, 12 products, two editorial motion loops, responsive collection pages, full product galleries, bag and selection review. Static-host-compatible hash routing.

See docs/expansion-design.md for the design system and docs/expansion-assets.json for asset provenance. scripts/prepare-expansion.mjs prepares generated image outputs and motion formats. No payments, real orders or newsletter submission backend.
